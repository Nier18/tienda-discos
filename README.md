# Tienda de discos

Proyecto final de Programación para Internet.

Sitio de una tienda de discos hecho con PHP, MySQL y Bootstrap 5, a partir del template [Shop Homepage](https://startbootstrap.com/template/shop-homepage) de Start Bootstrap (licencia MIT).

## Cómo correrlo

```
docker compose up -d --build
```

- Sitio: http://localhost:8080
- phpMyAdmin: http://localhost:8081
